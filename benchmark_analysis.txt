BENCHMARK RESULTS ANALYSIS
==========================================================================================
Old implementation: benchmark_old_no_utf8.txt
New implementation: benchmark_new_utf8.txt

COLUMN DEFINITIONS:
------------------------------------------------------------------------------------------
ns/op       Nanoseconds per operation - how long each function call takes.
            Lower is better. 1000 ns = 1 microsecond, 1,000,000 ns = 1 millisecond.

B/op        Bytes allocated per operation - total heap memory allocated per function call.
            Lower is better. Indicates memory efficiency.

allocs/op   Number of heap allocations per operation - how many times memory was allocated.
            Lower is better. Each allocation has overhead and creates work for the GC.

min-ns/op   Fastest (minimum) time recorded across 10 benchmark runs.
max-ns/op   Slowest (maximum) time recorded across 10 benchmark runs.
avg-ns/op   Average time across all 10 benchmark runs.

Diff        Absolute difference in nanoseconds between old and new implementation.
Diff %      Percentage change from old to new implementation.
------------------------------------------------------------------------------------------
